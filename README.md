# ナインテクノ コーポレートサイト

Figmaデザイン（1ページ構成 / デスクトップ・モバイル対応）をもとにコーディングした静的サイトです。

## 構成

```
index.html          … ページ本体（1ファイル構成）
assets/css/style.css … スタイル一式
assets/js/script.js   … スクロール演出・トップへ戻るボタン
assets/img/           … 画像（下記の通り現在はプレースホルダー）
```

## プレビュー方法

ビルド不要の静的サイトです。リポジトリ直下で簡易サーバーを立てて確認してください。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 画像について（要対応）

このセッションを実行している環境からは `figma.com` への外部通信がネットワークポリシーによりブロックされており、Figma上の実写真をダウンロードできませんでした。そのため `assets/img/*.jpg.svg` はすべて**レイアウト確認用のプレースホルダー画像**（グレーのカメラアイコン＋差し替え箇所の説明文）になっています。

実際の写真に差し替える際は、同じファイル名（例: `hero-keyvisual.jpg.svg` → `hero-keyvisual.jpg`）で書き出し、`index.html`内の該当する `src` 属性を書き換えてください。各プレースホルダーには元のFigma上のサイズ・用途をラベルとして表示しています。

## その他の未実装・要確認事項

- COMPANYセクションの地図は仮でGoogleマップの埋め込み（住所検索ベース）にしています。正式な座標・店舗情報があれば差し替え可能です。
- お問い合わせのメールリンク（`mailto:info@example.com`）は仮アドレスです。正式な問い合わせ先に差し替えてください。
- 代表者の署名フォント（Figma上の「A-OTF 教科書体」相当）は有償フォントのため、Webフォントとして読み込めるフォントに代替しています。
